Obtenir une clé Gemini gratuite

Pour lire le texte de vos captures d'écran, l'application utilise l'intelligence artificielle de Google. C'est gratuit et cela prend 2 minutes :

  1. Allez sur le site Google AI Studio (cliquez ici).
  2. Connectez-vous avec votre compte Google standard.
  3. Cliquez sur le bouton bleu "Get API key" (Obtenir une clé API) en haut à gauche.
  4. Cliquez sur "Create API key", puis choisissez un projet ou créez-en un.
  5. Copiez la clé générée (elle commence par AIzaSy...) et collez-la dans la case ci-dessous dans l'application.

Sécurité : Votre clé reste sur votre téléphone. Aucun serveur intermédiaire ne la reçoit.
